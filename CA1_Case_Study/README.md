# CA1 Case Study

**BlackSpot Miner: A Case Study-Based Data Mining Analysis of Severe Road Collisions**

VESIT D15A Group 09 — Jaiprakash Talreja (54), Adarsh Singh (52), Vidushi Singh (53), Piyush Shukla (49)

- **Report:** [`REPORT/DMBI CA1 Case Study Report Group 09.pdf`](<REPORT/DMBI CA1 Case Study Report Group 09.pdf>)
- **Reference paper:** Kumar, S. and Toshniwal, D. (2015). A data mining framework to analyze road accident data. *Journal of Big Data*, 2, 26. https://doi.org/10.1186/s40537-015-0035-y

The case study frames the problem: a road authority has a limited safety budget and must decide where to act. It sets out the data mining process (clustering for hotspots, association rules for causes, prediction for next-year risk) that is implemented in the [CA2 Mini Project](../CA2_Mini_Project).
